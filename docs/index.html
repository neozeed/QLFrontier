Frontier. On the Sinclair QL.

Two versions of the QL port, running live through QLBox WebAssembly. Choose a page, start the machine, and let its ZIP drive boot the game.

Frontier 0 →Original four-colour Mode 4 view and panel, with readable text.Frontier 8 →Eight-colour flight view and readable HUD, with Mode 4 information screens.

Each page has 8×, 12×, 16× and 20× CPU controls, ZIP loading, fullscreen and a drive download for keeping saved commanders.

QLBox R24 · Minerva · 1 MB RAM · Frontier QL 07a. Desktop keyboard and mouse recommended. These Frontier builds do not include game audio.
